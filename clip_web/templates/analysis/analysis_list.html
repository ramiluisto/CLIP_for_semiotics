About CLIP Analyses

CLIP (Contrastive Language-Image Pre-training) analyzes images by comparing them with text descriptions. Each analysis:

  • Compares every image in a dataset with your text prompts
  • Generates similarity scores showing how well images match each prompt
  • Enables semantic search and categorization of visual content
  • Runs asynchronously in the background for large datasets
